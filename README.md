# Credit Card Fraud Detection Using Machine Learning

## 1. Project Overview

Credit Card Fraud Detection is a Machine Learning project that identifies potentially fraudulent credit card transactions. It uses a **Random Forest Classifier** to classify transactions as genuine or fraudulent based on transaction data.

The main goal of this project is to help detect suspicious transactions and reduce financial fraud.

## 2. Objectives

- Analyze credit card transaction data.
- Understand genuine and fraudulent transaction patterns.
- Train a Machine Learning model to detect fraud.
- Evaluate model performance using different metrics.
- Identify important features that influence predictions.

## 3. Technologies Used

- **Python:** Programming language.
- **Pandas:** Data manipulation and analysis.
- **NumPy:** Numerical operations.
- **Matplotlib:** Data visualization.
- **Seaborn:** Statistical data visualization.
- **Scikit-learn:** Machine Learning and model evaluation.
- **Google Colab:** Development environment.

## 4. Dataset

The project uses a dataset named `creditcard.csv`.

The dataset contains transaction information and a target column named `Class`, which indicates the type of transaction:

- **0 – Genuine Transaction**
- **1 – Fraudulent Transaction**

The dataset is loaded and analyzed to understand its structure, identify missing values, and examine the distribution of genuine and fraudulent transactions.
